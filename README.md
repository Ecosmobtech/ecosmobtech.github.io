# ecosmobtech.github.io

Official GitHub Pages site of **Ecosmob Technologies** - an end-to-end software services and solutions provider for VoIP, telecom, web, mobile and cloud engineering.

**Live site:** https://ecosmobtech.github.io/
**Company website:** https://www.ecosmob.com/

## About this repository

This repository hosts the static source of the Ecosmob GitHub Pages user site.

| Item | Value |
| --- | --- |
| Publishing source | `main` branch, `/ (root)` folder |
| Entry file | `index.html` |
| Build | GitHub Pages (pages-build-deployment workflow) |

## Local preview

Clone the repository and open `index.html` in a browser, or serve it with any static server:

    git clone https://github.com/Ecosmobtech/ecosmobtech.github.io.git
    cd ecosmobtech.github.io
    python3 -m http.server 8080

Then visit http://localhost:8080/

## Updating the site

1. Edit `index.html` on the `main` branch.
2. Commit the change.
3. GitHub Pages rebuilds and republishes automatically - allow a few minutes for the change to appear.
